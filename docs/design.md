# ColorfulTalk V1 の内部設計

V1 は、ColorfulTalk V3 の方式（藤崎モデルの抑揚、境界ごとの遷移、LF モデルの声帯音源、
Klatt 型の合成器）を **整数演算だけ** に移したものです。合成コア（`fx/`）は V2 と共有します。

```
記号列 ─ ct_koe ─▶ モーラ列・アクセント句
       ─ fx_prosody ─▶ セグメント列（長さ・振幅）＋ 藤崎モデルの指令
       ─ fx_frame ─▶ 4ms（32 サンプル）ごとの合成パラメータ
       ─ fx_synth ─▶ 8kHz の PCM
```

## 整数化の決まり

| 項目 | 表し方 |
|---|---|
| 型 | `int8_t` / `int16_t` / `int32_t` / `uint*_t` だけを使う。`int` の幅に依存しない |
| 時間 | ms の整数（`int32_t`） |
| 周波数・帯域幅 | Hz の整数（`int16_t`） |
| 振幅 | 線形 Q12（60dB = 4096）。dB からは表で変換 |
| 声の高さ | log2 の Q10（1024 = 1 オクターブ）。Hz へは 2^x の表で変換 |
| 共振器の係数 | Q13（反共振器は Q10） |
| 信号 | `int16_t`。共振器の出力ごとに飽和させる |
| 乗算 | 16bit × 16bit → 32bit。64bit 演算は使わない |
| 除算 | フレームごと（4ms に数回）だけ。サンプルごとの処理には除算がない |

## 表（fx/src/fx_tables.c、生成）

`tools/fxgen.c` が浮動小数点で計算して C の表にします（`cmake --build build --target fxgen_run`）。

| 表 | 内容 |
|---|---|
| `FX_COS` | cos(πi/256)。共振器の係数 cos(2πf/fs) を線形補間で引く |
| `FX_EXPBW` | exp(−π·bw/fs)、16Hz 刻み |
| `FX_DB` | dB → 線形 Q12 |
| `FX_EXP2` | 2^(i/256)。声の高さを Hz に |
| `FX_GP` / `FX_GA` | 藤崎モデルのフレーズ成分（16ms 刻み）・アクセント成分（4ms 刻み） |
| `FX_SIN` | 声のゆっくりしたゆらぎ |
| `FX_CSC` / `FX_VSC` | 話速に対する子音・母音の長さの倍率（10% 刻み） |

## 声（src/ct1_voices.c、生成）

声 1 つは `CtFxVoice` 構造体（約 150 バイト）で、基準 F0、抑揚の幅、声道倍率、B1 の追加幅、
音源の高域減衰、気息音、ゆらぎ、出力ゲイン、声門が閉じる位置、LF パルス 1 周期（64 点, Q14）を持ちます。
LF パルスは `tools/fxgen.c` が Rd から計算します。出力ゲインは 8kHz で実測した音量で声ごとにそろえています。

V1 はビルド時に `CT1_VOICE_ID` で 1 つだけ選び、その声だけを ROM に入れます。

## 合成器（fx/src/fx_synth.c）

- 声帯音源: 16bit の位相（1 周期 = 65536）で LF パルス表を線形補間して引く。周期の頭でゆらぎ（ジッタ・シマー）を決める
- 高域の減衰: 1 次ローパス（係数は声ごと）
- 雑音: 16bit の線形帰還シフトレジスタ。一様乱数 2 つの平均でおおよそ正規分布にする
- 気息音は声門が閉じている間 0.4 倍
- カスケード枝: 鼻腔の極 → 鼻腔の零（鼻音のときだけ） → F4 … F1。8kHz で出せない周波数の共振器は飛ばす
- パラレル枝: 摩擦用の 2 共振器（共振周波数でのゲインが 1 になるよう、平方根を整数で計算）＋バイパス
- 放射特性（1 次差分）、なめらかなリミッタ

## 8kHz に合わせた変更（V3 との違い）

| 項目 | V3（16kHz） | V1（8kHz） |
|---|---|---|
| カスケードの共振器 | F1〜F5 | F1〜F4（3680Hz 以上は使わない） |
| 摩擦用の共振器 | 3 つ | 2 つ |
| さ行の雑音 | 4.8kHz と 6.8kHz の山 | 3.5kHz の山＋高域のバイパス |
| しゃ行の雑音 | 2.9kHz と 4.3kHz | 2.7kHz と 3.5kHz |
| フレーム | 2ms | 4ms（32 サンプル） |
| 先読み | 250ms | 200ms |
| 声の作り方 | パラメータを実行時に指定 | 声の構造体を ROM に置く |

## 作業領域

`CtFxWork`（4,928 バイト）の主な中身:

| 部分 | 大きさ |
|---|---|
| モーラ 256 個 | 2,048 バイト |
| アクセント句 64 個 | 384 バイト |
| セグメントの待ち行列 32 個 | 約 2,000 バイト |
| 藤崎モデルの指令 16 個 | 約 200 バイト |
| フレーム・合成器の状態 | 約 300 バイト |
